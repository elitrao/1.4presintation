# AI Аналитик · Обновление 1.4

Внутренняя сайт-презентация для руководства из четырёх слайдов. Главная мысль: сократить и упростить путь от первого входа до результата, с которым можно работать.

Стиль перенесён из локальной презентации по тарификации: фон #191919, Manrope, фирменный оранжевый #d96a1b, логотип IQ Group. Шрифты включены локально. Синие и фиолетовые акценты отсутствуют.

Содержание основано на подтверждённом пользователем составе релиза: упрощение главной, настроек, баз знаний, шаблонов, документов, отчётов и сотрудников; новые страницы «Помощь» и «Предложить идею». Схемы концептуальные: не скриншоты интерфейса и не точная спецификация новых функций. Количество шагов в схеме обозначает смысловые этапы, не измеренные клики. График отчётов иллюстрирует результат, не клиентскую статистику. Ускорение и эффект на конверсию не заявляются без данных.

Навигация: кнопки, стрелки клавиатуры, Page Up / Down, пробел, Home / End и прямые ссылки #slide-1 … #slide-4. Полноэкранный режим. Есть адаптивная компоновка, уменьшенная анимация и режим печати.

Запуск: `python -m http.server 4176 --bind 127.0.0.1 --directory dist`.

По уточнению пользователя удалены слайды с деталями отдельных страниц. Итоговая структура: главная мысль, путь пользователя, общий список страниц, итог.

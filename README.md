# AI Аналитик 1.4 — убираем всё лишнее

Внутренняя сайт-презентация для руководства. Шесть слайдов:
1. Убираем всё лишнее: меньше действий от первого входа до результата.
2. Нужные действия оставляем, лишние убираем. Схематичный длинный путь с обходами превращается в прямую линию; анимацию можно повторить.
3. Проблема и цель обновления: перейти от работы с интерфейсом к работе с результатом.
4. Примеры короткого пользовательского пути в Google, ChatGPT, Uber и Canva.
5. Один список всех перерабатываемых страниц и две новые страницы.
6. Цель: зайти, сделать задачу, получить результат с минимумом действий между шагами.

Состав релиза подтверждён пользователем: главная, настройки, базы знаний, шаблоны, документы, отчёты, сотрудники; добавляются «Помощь» и «Предложить идею». Схема показывает принцип сокращения ненужных действий, а не реальные измеренные клики или конкретную последовательность текущего интерфейса. Численных обещаний по скорости и конверсии нет.

Стиль презентации по тарификации: #191919, оранжевый #d96a1b, Manrope, логотип IQ Group. Шрифты включены локально.

Управление: кнопки, стрелки, Page Up / Down, пробел, Home / End; ссылки #slide-1 … #slide-6; полноэкранный режим. Поддержаны мобильная компоновка, уменьшенная анимация и печать.

Локальный просмотр: python -m http.server 4176 --bind 127.0.0.1 --directory dist
